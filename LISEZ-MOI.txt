TROUVE TA CLINIQUE - GUIDE D'ENTRETIEN
======================================

IMPORTANT
---------
Ce guide décrit le site en production (branche main, trouvetaclinique.ca). Les changements se
préparent et se relisent sur la branche brouillon (apercu.trouvetaclinique.ca) avant d'être
fusionnés dans main par pull request.


ADRESSES PRINCIPALES
--------------------
/ ........................ accueil du site
/monteregie/ ............. carte complète
/monteregie-est/ ......... carte Montérégie-Est et seule PWA installable
/monteregie-centre/ ...... carte Montérégie-Centre
/monteregie-ouest/ ....... carte Montérégie-Ouest
/cliniques/ .............. répertoire général
/ptem/ et /amp/ .......... guides d'information


LES FICHIERS IMPORTANTS
-----------------------
data.json ................ toutes les données publiques de la carte
scripts/carte.template.html
                          gabarit des cartes complète / Centre / Ouest
scripts/carte-est-sq.template.html
                          gabarit Santé Québec de Montérégie-Est
scripts/publier-regions.js
                          fabrique les quatre cartes
scripts/generer-pages-seo.js
                          fabrique l'accueil, les répertoires, les fiches, les RLS et le sitemap
scripts/slugs.json ........ conserve les adresses web existantes
assets/seo-pages.css ...... style des pages web hors cartes
sw.js ..................... mode hors ligne de Montérégie-Est seulement
manifest-est.webmanifest .. installation de la carte Montérégie-Est
PTEM2027_v2.gs ............ archive Apps Script (export ; ne publie pas tout seul)
scripts/reconciliation-maitre-33-absents.csv
                          33 cliniques publiées à réintégrer dans la base maître
scripts/RECONCILIATION-MAITRE.md
                          marche à suivre pour la réconciliation Sheet ↔ JSON
scripts/NOTES-REDIRECTIONS-SEO.md
                          redirections HTML + 301 Cloudflare à prévoir

Ne pas modifier à la main les pages générées. Le changement serait effacé à la prochaine
génération.

Les courriels de recrutement (champ personneRessource) sont publiés sur les fiches
depuis le 2 septembre 2026 (PUBLIER_COURRIELS = true).


METTRE À JOUR LES DONNÉES
-------------------------
1. Modifier data.json.
2. Vérifier les virgules, guillemets et identifiants uniques.
3. Enregistrer la modification.
4. Le robot GitHub met la date à jour, régénère les pages et lance ses vérifications.

Commandes équivalentes sur un ordinateur :

  node scripts/generer-pages-seo.js
  node scripts/publier-regions.js


DIFFÉRENCE ENTRE UNE CLINIQUE ET UN ÉTABLISSEMENT
-------------------------------------------------
CLINIQUE
- categorie ne vaut pas "etablissement";
- visible:false retire la clinique de la carte et des pages;
- recrutementActif:false la conserve, mais elle apparaît seulement avec « Toutes les cliniques »;
- peut avoir une fiche, des favoris, des notes et participer au comparatif.

ÉTABLISSEMENT
- categorie vaut "etablissement";
- apparaît dans la couche « Établissements », même si visible:false est encore présent;
- sert seulement de repère informatif;
- n'entre jamais dans la recherche, les favoris, les notes, le classement ou le comparatif.

Le bouton (i) de la carte explique cette différence aux visiteurs.


INFORMATIONS À NE PAS PUBLIER
-----------------------------
- courriels personnels ou de recrutement;
- montants négociés;
- notes internes;
- renseignements personnels non autorisés;
- nom protégé Santé Québec configuré dans le secret NOM_PROTEGE_SANTE_QUEBEC.

Le champ notes de data.json n'est pas un espace de publication.


PWA ET MODE HORS LIGNE
----------------------
Seule la carte /monteregie-est/ est installable et gérée par sw.js.

Après une modification d'un fichier mis en cache, augmenter la version dans sw.js :

  trouve-clinique-est-v52  ->  trouve-clinique-est-v53

Une modification de data.json ne demande normalement pas ce changement, car les données sont
chargées en priorité depuis le réseau.

Le fichier manifest.json est un ancien vestige non référencé. Ne pas le relier à une page.


HEADERS
-------
- Les cartes conservent le header V4 Santé Québec.
- Les autres pages utilisent le header bleu marine avec le logo et « Trouve ta clinique ».
- Les boutons de navigation sont générés automatiquement. Ne pas les recopier dans chaque page.


FICHIERS À NE PAS SUPPRIMER
---------------------------
CNAME ...................... maintient le domaine trouvetaclinique.ca
google0e6f553795bbb4a9.html . vérification Google Search Console
robots.txt / sitemap.xml ... référencement
.github/ ................... génération et contrôles automatiques
scripts/slugs.json .......... mémoire des adresses web existantes
vendor/ et ses licences ..... bibliothèques cartographiques locales


TEST LOCAL
----------
Dans le dossier du projet :

  python3 -m http.server 8000

Puis ouvrir http://localhost:8000. Ne pas ouvrir index.html directement avec file://.


CHANGEMENT D'ANNÉE PTEM
-----------------------
La marque « Trouve ta clinique » ne change jamais.

Mettre à jour seulement :
1. les étiquettes PTEM dans scripts/carte.template.html;
2. short_name dans manifest-est.webmanifest;
3. le titre iOS dans scripts/publier-regions.js;
4. les faits et sources de la page PTEM.

Ne jamais renommer les clés localStorage dtmf-mtg-*, l'identifiant du manifeste ou le domaine.
